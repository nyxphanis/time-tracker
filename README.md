# Time Tracker Application

A simple desktop application for tracking work hours and generating monthly reports.

## Features
- Start/Stop tasks
- Save work logs locally
- Export monthly reports as CSV

## Requirements
- Python 3.x
- Pandas library

## Usage
1. Run the application using the executable file or Python script.
2. Start and stop tasks to log work periods.
3. Export reports for submission to HR.
